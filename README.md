# L.I.B.O.T – Food and Hospitality Module

##  Project Description

The L.I.B.O.T (Local Itinerary-Based Orientation & Travel Guide) System is a mobile tourism platform designed to help tourists and locals explore the 3rd District of Camarines Sur.

This module focuses on food and hospitality services, allowing users to discover restaurants, cafes, and lodging establishments. It provides organized, accurate, and up-to-date information, helping users make better travel decisions efficiently.

## Key Features

* Restaurant and Lodging Listings
* Search and Filter Functionality
* Personalized Recommendations
* Admin Update System

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Tools: XAMPP

## Installation Guide

1. Install XAMPP
2. Clone the repository:
   git clone https://github.com/yourusername/libot-food-hospitality-module.git
3. Move the project folder to htdocs
4. Start Apache and MySQL in XAMPP
5. Import the database into phpMyAdmin
6. Run the system in browser:
   http://localhost/libot-food-hospitality-module
